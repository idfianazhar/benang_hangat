# Benang Hangat Nenek 🧶

Game pixel-art bertema hangat dan nostalgia tentang merajut kenangan, kasih sayang, dan kehangatan nenek. Dibangun menggunakan teknologi web murni (HTML5, Tailwind CSS, dan procedural Web Audio API synthesizer).

---

## 🎮 Fitur Utama

- **Visual Pixel Art Estetik**: Tampilan bernuansa CRT monitor retro, palet warna hangat, dan font pixel retro (*Press Start 2P* & *Pixelify Sans*).
- **Audio Synthesizer Terintegrasi**: Menggunakan Web Audio API untuk menghasilkan melodi chord dan arpeggio yang menenangkan (*m-taku Komorebi motif*) tanpa ketergantungan file eksternal wajib.
- **Interaksi Sentuh & Responsif**: Mendukung gameplay di layar desktop maupun perangkat mobile/layar sentuh.

---

## 🚀 Cara Menjalankan Secara Lokal

Buka file `index.html` langsung di peramban (browser) modern favorit Anda:

```bash
# Atau jalankan server lokal sederhana
npx serve .
```

## 🌐 Deployment (Vercel)

Proyek ini telah dikonfigurasi siap deploy ke **Vercel** sebagai static web application.
- Cukup hubungkan repositori ini ke akun [Vercel](https://vercel.com/new).
- Framework Preset: **Other** / Static Site.
- Output Directory: `./` (Root).
